# yesterday-detailing-site

This is the official website for my car detailing business, YesterDay Car Detailing.

## Purpose
The goal of this project is to create a clean, modern, and mobile-friendly website to attract customers, showcase services, and drive bookings.

## Features
- Home page with hero section and call-to-action
- Services overview (interior, exterior, full detail)
- Pricing section
- About section
- Contact / booking section
- Mobile-first responsive design

## Tech Stack
- HTML
- CSS
- JavaScript (vanilla)

## How to Run Locally
1. Clone the repository:

git clone https://github.com/YOUR-USERNAME/yesterday-car-detailing-site.git

2. Open the folder
3. Open `index.html` in your browser  
OR run a local server:

npx serve .
